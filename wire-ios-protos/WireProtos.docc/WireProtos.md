# ``WireProtos``

Defines Swift models for shared Protobuf data structures.

## Overview

WireProtos contains the generated Swift data structures for the Profobuf data structures that are shared across all Wire platforms.

### How to update protobufs

1. Have protobuf installed: `brew install protobuf; brew install swift-protobuf` 
2. `cd wire-ios-protos`
3. `./Scripts/compile-swift-protos.sh`
4. commit the `*.pb.swift` files
